# Hey, I'm Dany 👋

I'm a Principal Software Engineer who gets unreasonably excited about understanding how things work under the hood — and then rebuilding them from scratch. Whether it's writing a [compiler](https://github.com/dkhalife/compiler), playing with [graph algorithms](https://github.com/dkhalife/GraphAlgorithms), or building [developer tools that save engineers hours every day](https://github.com/dkhalife/azure-pipelines-debugger), I'm happiest when I'm deep in creator mode.

I believe the best software is **software you own**. That's why I self-host everything I can, and build tools that put privacy and data ownership first.

## 🔧 What I Build

### Self-Hosted & Open Source
- **[Task Wizard](https://github.com/dkhalife/task-wizard)** — Privacy-first task management app. Your data stays yours.
- **[Traefik Country Block](https://github.com/dkhalife/traefik-country-block)** — A Traefik middleware plugin that does geo-blocking entirely offline. Zero external API calls — all lookups happen in-memory.
- **[Meross Local Broker](https://github.com/dkhalife/meross-local-broker)** — Home Assistant addon that keeps IoT device communication LAN-local via MQTT.
- **[Eclipse Mosquitto with Auth](https://github.com/dkhalife/eclipse-mosquitto-with-auth)** — A Mosquitto fork with drop-in authentication.

### Engineering Productivity
- **[Azure Pipelines Debugger](https://github.com/dkhalife/azure-pipelines-debugger)** — VS Code extension that helps you understand YAML template expansion for Azure Pipelines. Breakpoints, call stacks, watch expressions — the full debugging experience, but for CI/CD templates processing.
- **[Azure Log Analytics MCP](https://github.com/dkhalife/azure-log-analytics-mcp)** — An MCP server that lets AI assistants query your Azure Log Analytics workspaces using KQL.

### Home Automation
- **[Home Assistant Blueprints](https://github.com/dkhalife/hassio-blueprints)** — Reusable automation blueprints for Home Assistant.
- **[Azure Backup](https://github.com/dkhalife/azure-backup)** — Docker image for automated backups to Azure Blob Storage.
